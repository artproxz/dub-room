# DubRoom Studio

DubRoom — совместный браузерный мини-DAW для шуточной озвучки видео компанией до трёх человек.

## Как работает

1. Ведущий создаёт комнату и загружает видео.
2. Все участники видят один общий таймлайн.
3. Ведущий задаёт рабочий участок `IN → OUT`.
4. Каждый участник включает или выключает `REC` на своей дорожке.
5. Ведущий запускает запись: `3 → 2 → 1`, фильм идёт синхронно, но уже записанные голоса во время REC не слышны.
6. У armed-участников микрофон записывается локально. После остановки на их дорожках появляются отдельные AudioClip с waveform.
7. Клипы можно двигать по таймлайну, менять их громкость и удалять через ПКМ.
8. Каждый нажимает `ГОТОВ`. Когда готовы все подключённые участники, DubRoom автоматически проигрывает выбранный участок с общим миксом голосовых клипов.

## Возможности MVP 0.2

- до 3 участников и приглашение по ссылке;
- HTTPS-совместимый доступ к микрофону;
- синхронизированный фильм и транспорт ведущего;
- мини-DAW / FL Studio-подобный таймлайн;
- отдельная дорожка на каждого участника;
- `REC ON/OFF` индивидуально для каждого;
- цвет дорожки пользователя;
- рабочий диапазон `IN/OUT`;
- автоматический countdown перед записью;
- во время REC все существующие voice-клипы замьючены;
- waveform каждого записанного аудиоклипа;
- несколько перекрывающихся клипов на одной дорожке с автоматическими визуальными lanes;
- drag аудиоклипов по времени;
- индивидуальная громкость клипа;
- ПКМ → прослушать / выбрать как участок / удалить;
- собственные клипы яркие, чужие визуально обесцвечены;
- `Ctrl + колесо` — zoom таймлайна;
- средняя кнопка мыши + drag — панорама;
- `Shift + колесо` — горизонтальная прокрутка;
- `ГОТОВ` у каждого участника и автоматическое итоговое прослушивание;
- корректные HTTP `Range` и `HEAD` для больших MP4;
- zero-dependency Node.js сервер;
- автоматический smoke-test;
- Docker.

## Стек

- Node.js 22+ (встроенный `http`);
- Vanilla JavaScript;
- Server-Sent Events;
- MediaRecorder API;
- Web Audio API;
- локальное файловое хранилище.

Внешние npm-зависимости не используются.

## Запуск

```bash
npm start
```

Открыть `http://localhost:3001`.

Проверки:

```bash
npm run check
npm test
```

## Render

- Build Command: `npm run check`
- Start Command: `npm start`
- Health Check: `/api/health`

Для микрофона в интернете необходим HTTPS. Render выдаёт HTTPS автоматически.

## Ограничения текущей версии

- комнаты и проектная модель находятся в RAM и теряются после рестарта процесса;
- видео и аудио хранятся на локальном диске инстанса, поэтому бесплатный Render удалит их при redeploy/restart;
- нет финального экспорта всей озвучки в MP4;
- нет аккаунтов: секретом комнаты является ссылка;
- громкость клипа в MVP регулируется от 0 до 100%;
- браузер должен уметь декодировать исходное видео (рекомендуется MP4 H.264).

Следующий инфраструктурный этап для постоянного использования — R2/S3 для медиа и Redis/БД для состояния комнаты.

> Используйте только видео, на обработку которых у вас есть необходимые права.
