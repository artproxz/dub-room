# DubRoom

Мини-сервис совместной шуточной озвучки видео для компании до 3 человек.

## Идея

Во время записи каждый участник слышит только исходное видео (в MVP оригинальная дорожка заглушена) и **не слышит других участников**. При этом у каждого на экране видны живые уровни микрофонов всех троих. После остановки все локальные голосовые дорожки загружаются отдельно, и комната автоматически запускает совместную прослушку записанного дубля.

## Что уже есть в MVP

- комнаты до 3 участников;
- приглашение по ссылке/коду;
- запрос разрешения на микрофон при входе;
- загрузка видео ведущим;
- синхронизация Play/Pause/Seek ведущего;
- countdown `3…2…1` перед записью;
- одновременная локальная запись всех микрофонов через `MediaRecorder`;
- живые waveform-индикаторы активности голоса без передачи живого аудио другим участникам;
- синхронный Stop;
- отдельная аудиодорожка каждого участника;
- автоматическая прослушка сразу после загрузки всех дорожек;
- список дублей;
- повторное прослушивание;
- выбор удачного дубля;
- перезапись того же временного участка с автоматическим Stop;
- удаление неактивной комнаты и файлов через 48 часов;
- адаптивный тёмный интерфейс;
- Dockerfile и docker-compose.

## Почему без WebRTC

В этом сценарии WebRTC для живого разговора не нужен: смысл игры как раз в том, что участники **не знают, что говорят остальные**, пока не закончится дубль.

Для realtime-событий MVP использует Server-Sent Events (SSE), а команды отправляются обычным HTTP. Для трёх человек этого более чем достаточно и позволяет запускать приложение без внешних npm-зависимостей.

## Стек

- Node.js 22 — встроенный HTTP-сервер;
- Vanilla JavaScript;
- Server-Sent Events (SSE);
- MediaRecorder API;
- Web Audio API;
- локальное файловое хранилище.

Проект специально сделан **zero-dependency**: `npm install` не требуется.

## Запуск

```bash
npm start
```

Открыть:

```text
http://localhost:3001
```

Или:

```bash
node server/index.js
```

Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

```bash
docker compose up --build
```

## Важно для микрофона

Браузеры разрешают `getUserMedia()` на `localhost` и на HTTPS-сайтах. Поэтому при публикации в интернет сервис должен работать через HTTPS.

## Хранение

Временные файлы складываются в `./data` и не коммитятся в Git. Комната удаляется через 48 часов неактивности.

## Ограничения текущего MVP

- состояние комнаты хранится в памяти процесса и теряется после рестарта сервера;
- локальное файловое хранилище рассчитано на один серверный инстанс;
- пока нет финального FFmpeg-рендера выбранных дублей в единый MP4;
- нет аккаунтов и авторизации — секретом комнаты является ссылка;
- автопрослушка зависит от браузерной политики autoplay; после разрешения микрофона и взаимодействия со страницей современные браузеры обычно разрешают запуск, но при блокировке ведущий может нажать «Послушать» повторно.

## Что добавить следующим этапом

1. FFmpeg-рендер выбранных дублей в итоговый MP4.
2. Cloudflare R2 / S3 вместо локального диска.
3. Redis/БД для сохранения комнат после рестарта.
4. Регулировка громкости каждой голосовой дорожки.
5. Названия сцен и комментарии к дублям.

> Используйте только видео, на обработку которых у вас есть необходимые права.
